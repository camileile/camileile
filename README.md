## Projects I'm proud of

### 🔎 Lumen
`Next.js · TypeScript · Node.js · Express · Prisma · SQLite · OpenRouter`

A platform that uses AI to help analyze how reliable a web page or news article is. It has a web app, an API and a Chrome extension working together. I'm currently modernizing it step by step, with separate branches and pull requests for each phase.

### 🎧 ClipFlow
`Next.js · TypeScript · Python · FastAPI · yt-dlp · FFmpeg`

A web app to download public media from YouTube, TikTok, Instagram and X, with MP3 conversion. Shows real-time progress, speed and ETA, lets you cancel downloads, and has rate limiting and URL validation. The interface has a retro look inspired by 2000s software.

### 🛠️ Benvi
`TypeScript · Next.js · Node.js · MySQL`

Academic project: a marketplace that connects people to local service providers. I worked on authentication, user management, access levels, business rules and the database model, using a model/service/controller structure.
